# Zakirli (ذاكرلي)
Lecture summarizer + quiz + Arabic/English translation. Static PWA, no build step.
- Input: paste text, upload PDF/TXT/SRT/VTT, or dictate with the mic (Chrome).
- Without a key: on-device extractive summary, cloze/multiple-choice questions, flashcards; translation via Chrome's built-in Translator or the free MyMemory API.
- With a free Gemini API key (Settings tab, stored only in the browser): real summary, smarter quiz, better translation.
