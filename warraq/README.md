# وراق | Warraq PDF

Free, installable (PWA) PDF reader/editor that runs fully in the browser. Files never leave the device.

Features: annotate (pen, highlighter in 4 colors, shapes, text), edit existing text, sign (draw / from photo), stamps, merge, split, reorder/rotate/delete pages, images to PDF, compress, page numbers, watermark, tap-a-word translation, page/document/bilingual translation, offline summary + optional Gemini AI (summary, Q&A, flashcards), OCR (Tesseract), read aloud, auto-redact emails/phones/ID numbers, metadata cleaner, highlights export, flashcards, focus ruler, night/sepia modes.

Libraries: pdf.js, pdf-lib (vendored). OCR loads Tesseract.js from a CDN on first use.
